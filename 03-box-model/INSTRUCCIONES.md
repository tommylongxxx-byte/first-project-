# Ejercicio 3: Box Model

## Objetivos
- Entender el modelo de cajas de CSS
- Dominar margin, padding, border y dimensiones
- Aprender sobre display: block, inline, inline-block

## Conceptos clave

### Box Model (De afuera hacia adentro)
1. **Margin** - Espacio exterior (entre elementos)
2. **Border** - Borde alrededor del elemento
3. **Padding** - Espacio interior (dentro del borde)
4. **Content** - El contenido real (texto, imágenes)

### Valores de margin y padding
- `margin: 20px;` - 20px en todos los lados
- `margin: 10px 20px;` - 10px arriba/abajo, 20px izquierda/derecha
- `margin: 10px 20px 30px 40px;` - arriba, derecha, abajo, izquierda (clockwise)
- `margin: 0 auto;` - centrar horizontalmente

### Display
- `display: block;` - ocupa toda la línea (h1, p, div)
- `display: inline;` - ocupa solo el espacio que necesita (span, a)
- `display: inline-block;` - combinación de ambos

## Tareas

### Tarea 1: Experimenta con margin y padding
1. Crea 3 cajas (div) con diferentes colores
2. Agrega margin a cada una (diferente en cada lado)
3. Agrega padding a cada una
4. Agrega borders de diferentes estilos

### Tarea 2: Trabaja con dimensiones
1. Define width y height en las cajas
2. Prueba box-sizing: border-box (incluye padding y border en la dimensión)
3. Usa max-width para limitar el ancho

### Tarea 3: Centra elementos
1. Usa `margin: 0 auto;` para centrar una caja horizontalmente
2. Experimenta con diferentes valores
