# Ejercicio 1: Estructura HTML Básica

## Objetivos
- Entender la estructura básica de un documento HTML
- Aprender las etiquetas más comunes
- Comprender elementos semánticos

## Conceptos clave
- `<!DOCTYPE html>` - Define que es un documento HTML5
- `<html>` - Contenedor raíz
- `<head>` - Metadatos, título, referencias a CSS
- `<body>` - Contenido visible
- Etiquetas de contenido: `<h1>` a `<h6>`, `<p>`, `<a>`, `<img>`, `<ul>`, `<ol>`, `<li>`
- Etiquetas semánticas: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`

## Tareas

### Tarea 1: Crea un documento HTML básico
1. Crea un archivo `index.html`
2. Agrega la estructura HTML básica completa (doctype, html, head, body)
3. En el `<head>`, agrega:
   - Un `<title>`: "Mi Primera Página"
   - Una etiqueta `<meta charset="UTF-8">`
   - Una etiqueta `<meta name="viewport"...>`

### Tarea 2: Agrega contenido al body
1. Crea un encabezado con `<h1>`: "Bienvenido a mi página"
2. Agrega 2-3 párrafos con `<p>`
3. Crea una lista desordenada `<ul>` con 5 elementos
4. Crea una lista ordenada `<ol>` con 3 elementos
5. Agrega un enlace `<a href="https://ejemplo.com">` hacia cualquier sitio

### Tarea 3: Agrega estructura semántica
1. Envuelve el `<h1>` en un `<header>`
2. Envuelve el contenido principal en `<main>`
3. Agrega un `<footer>` al final con tu nombre y año

---

## Consejos
- Usa indentación (2 espacios) para que el código sea legible
- Siempre cierra las etiquetas
- Usa etiquetas semánticas cuando sea posible
