# Solución: Ejercicio 2 - CSS Selectores y Propiedades

## Explicación de la solución

### index.html
- El archivo HTML está completo con las clases e IDs necesarios
- `id="titulo"` en el `<h1>`
- `class="destacado"` en un párrafo

### style.css
- **Selector de elemento `body`**: Establece el color de fondo (`#e8f4f8`) y el color de texto
- **Selector de elemento `h1`**: Color azul marino y tamaño 32px
- **Selector de elemento `p`**: Tamaño de fuente y line-height para mejor legibilidad
- **Selector de clase `.destacado`**: Fondo amarillo, borde naranja y padding
- **Selector de ID `#titulo`**: Añade una sombra al texto

## Conceptos importantes
- Los IDs son únicos en la página (usados para un elemento específico)
- Las clases pueden reutilizarse en múltiples elementos
- La especificidad: ID > clase > elemento
- El archivo CSS se vincula en el `<head>` con `<link>`

## Mejoras que podrías hacer
- Agregar más clases
- Experimentar con diferentes colores
- Probar diferentes font-families (Google Fonts)
- Hacer que el código sea más "responsivo" (para diferentes tamaños de pantalla)
