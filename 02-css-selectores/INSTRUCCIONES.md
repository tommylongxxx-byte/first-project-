# Ejercicio 2: CSS Básico - Selectores y Propiedades

## Objetivos
- Entender cómo vincular CSS a HTML
- Aprender selectores (elemento, clase, ID)
- Dominar propiedades básicas de CSS

## Conceptos clave

### Selectores
- **Selector de elemento**: `h1 { }` - aplica a todos los `<h1>`
- **Selector de clase**: `.mi-clase { }` - aplica a elementos con `class="mi-clase"`
- **Selector de ID**: `#mi-id { }` - aplica a un elemento con `id="mi-id"`
- **Selector universal**: `* { }` - aplica a todos los elementos

### Propiedades comunes
- `color` - color del texto
- `background-color` - color de fondo
- `font-size` - tamaño del texto
- `font-family` - tipo de letra
- `text-align` - alineación (left, center, right)
- `margin` - espacio externo
- `padding` - espacio interno

## Tareas

### Tarea 1: Crea un archivo CSS y vinculalo
1. Crea un archivo `style.css` en esta carpeta
2. En el `<head>` del `index.html`, agrega: `<link rel="stylesheet" href="style.css">`

### Tarea 2: Estiliza con selectores básicos
En `style.css`, agrega:
1. Selector de elemento `body`: color de fondo azul claro, color de texto oscuro
2. Selector de elemento `h1`: color azul marino, tamaño 32px
3. Selector de elemento `p`: tamaño 16px, line-height 1.6

### Tarea 3: Agrega clases y IDs
1. En `index.html`, agrega `class="destacado"` a un párrafo
2. Estiliza `.destacado` con fondo amarillo y borde
3. Agrega `id="titulo"` al `<h1>`
4. Estiliza `#titulo` con text-shadow
