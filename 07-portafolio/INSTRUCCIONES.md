# Ejercicio 7: Proyecto Integrador - Portafolio Personal

## Objetivo
Crear un portafolio personal combinando todo lo aprendido: HTML semántico + CSS avanzado + Responsive Design

## Requisitos del proyecto

### Secciones obligatorias
1. **Header/Nav** - Navegación principal
2. **Hero Section** - Sección principal con tu nombre y especialidad
3. **About** - Información sobre ti
4. **Skills** - Habilidades técnicas
5. **Projects/Portfolio** - Tus proyectos (mínimo 3)
6. **Contact** - Formulario o información de contacto
7. **Footer** - Pie de página

### Requisitos técnicos
- ✅ HTML semántico (header, nav, main, article, section, footer)
- ✅ CSS sin framework (puro CSS)
- ✅ Responsive (funciona en móvil, tablet y desktop)
- ✅ Mínimo Flexbox o Grid para layouts
- ✅ Colores y tipografía profesionales
- ✅ Media queries para diferentes tamaños
- ✅ Efectos hover en botones/enlaces
- ✅ Buena accesibilidad (alt text en imágenes, contraste, etc.)

### Requisitos de diseño
- Colores coherentes y profesionales (máximo 3 colores base)
- Tipografía legible (máximo 2 fuentes)
- Espaciado consistente
- Alineación clara
- Botones interactivos
- Transiciones suaves (CSS transitions)

## Tareas

### Paso 1: Planificar el diseño
- Dibuja o describe el layout en papel
- Define la paleta de colores
- Elige las fuentes
- Decide breakpoints para mobile/tablet/desktop

### Paso 2: Crear la estructura HTML
- Completa la estructura de todas las secciones
- Usa etiquetas semánticas
- Asegura buen acceso

### Paso 3: Estilizar desktop
- Crea el CSS para la versión desktop completa
- Implementa Flexbox/Grid
- Agrega colores, tipografía y espaciado

### Paso 4: Hacer responsive
- Agrega media queries
- Prueba en diferentes tamaños
- Asegura que se vea bien en móvil

### Paso 5: Pulir detalles
- Añade transiciones y hover effects
- Verifica accesibilidad
- Optimiza el código

## Trucos de diseño
- Usa `box-shadow` para profundidad
- Crea contraste entre secciones con fondos diferentes
- Usa `opacity` para elementos secundarios
- Implementa `scroll-behavior: smooth;` para UX
- Usa `animation` para efectos sutiles
