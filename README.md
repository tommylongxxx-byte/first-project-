# Aprendizaje de HTML y CSS - Ejercicios Progresivos

Este proyecto contiene 7 ejercicios progresivos para aprender HTML y CSS desde lo básico hasta conceptos intermedios.

## Estructura de Ejercicios

### Ejercicio 1: Estructura HTML Básica
**Carpeta:** `01-html-basico/`
- Aprenderás: etiquetas HTML, estructura del documento, elementos semánticos
- Archivo: `index.html`

### Ejercicio 2: CSS Básico - Selectores y Propiedades
**Carpeta:** `02-css-selectores/`
- Aprenderás: selectores (elemento, clase, ID), colores, tipografía, espaciado
- Archivos: `index.html`, `style.css`

### Ejercicio 3: Box Model
**Carpeta:** `03-box-model/`
- Aprenderás: margin, padding, border, width, height, display
- Archivos: `index.html`, `style.css`

### Ejercicio 4: Flexbox
**Carpeta:** `04-flexbox/`
- Aprenderás: flex-direction, justify-content, align-items, flex-wrap
- Archivos: `index.html`, `style.css`

### Ejercicio 5: CSS Grid
**Carpeta:** `05-grid/`
- Aprenderás: grid-template-columns, grid-template-rows, grid-gap, grid-area
- Archivos: `index.html`, `style.css`

### Ejercicio 6: Responsive Design
**Carpeta:** `06-responsive/`
- Aprenderás: media queries, mobile-first, viewport meta tag
- Archivos: `index.html`, `style.css`

### Ejercicio 7: Proyecto Integrador - Portafolio Personal
**Carpeta:** `07-portafolio/`
- Aprenderás: combinación de HTML + CSS, diseño completo, buenas prácticas
- Archivos: `index.html`, `style.css`, `assets/` (imágenes)

---

## Cómo usar este material

1. **Abre cada carpeta en VS Code**
2. **Lee las instrucciones en el archivo `INSTRUCCIONES.md` de cada ejercicio**
3. **Completa los ejercicios sin ver la solución primero**
4. **Compara con `SOLUCION.md` para ver cómo hacerlo correctamente**
5. **Experimenta y modifica el código para consolidar aprendizaje**

---

## Consejos para aprender

- ✅ Practica escribir el código, no copies y pegues
- ✅ Lee la documentación de MDN Web Docs cuando no entiendas algo
- ✅ Abre los archivos HTML en el navegador para ver los cambios en tiempo real
- ✅ Usa las DevTools del navegador (F12) para inspeccionar elementos
- ✅ No avances al siguiente ejercicio hasta dominar el actual
